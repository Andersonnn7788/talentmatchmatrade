# TalentMatch AI Agent Reference

Use this doc when prompting Cursor code agents so every feature shares the same mental model, stack, and constraints.

# Platform Sides (Three-Sided Ecosystem)

TalentMatch operates as a **three-sided platform**, and all features must respect the permissions, views, and workflows of these user groups:

## 1. Students & Fresh Graduates (Candidate Side)

- Create account with resume upload (auto-parsed into profile).
- Manage education, experience, achievements, and job preferences.
- Participate in hackathons, business challenges, and case studies hosted on the platform.
- Submit projects, receive digital badges, and appear on leaderboards.
- Access Virtual Hiring Panel scores, Reverse Recruiter Agent results, and AI interview transcripts/summaries.
- Consent-based visibility for employers browsing their profile.

## 2. Employers / Recruiters (Employer Side)

- Post job listings (manually or via bulk upload).
- View candidate profiles (restricted by RLS + candidate consent).
- Access the Employer **Talent Command Center**, including:
  - Leaderboards  
  - Top projects  
  - Challenge winners  
  - Skill-gap analytics  
  - Hiring Panel summary insights
- Receive AI-ranked candidate recommendations generated by multi-agent workflows.

## 3. Admin / Judge / Event Host Dashboard (Operational Side)

A lightweight but essential interface for operating events and moderating content.

- Create and manage hackathons, business challenges, and case studies.
- View project submissions, run AI scoring, and assign winners.
- Approve/verify submissions before they appear publicly.
- Trigger generation of digital badges and QR verification URLs.
- Access internal logs for debugging submissions, badges, and events.
- Manage event timelines (open, close, publish results).
- Perform basic moderation: delete inappropriate content or spam.

**Note:**  
This dashboard is intentionally minimal for MVP (no advanced analytics).

## Core Stack Commitments
- Next.js (App Router, TypeScript) for the TalentMatch web app.
- Supabase for auth, Postgres, Storage, edge functions, and pgvector.
- Google Gemini Flash 2.5 for reasoning + explainability, Gemini Embeddings for semantic search.
- **LangGraph** (not LangChain.js) to orchestrate multi-agent flows, retries, and tool access.
- ElevenLabs for TTS; STT handled via [Google STT]. Voice cloning optional, not required for MVP.
- LangGraph flows run in Next.js API routes / Supabase edge functions, kept short-lived to fit serverless model.
- RAG pipeline pulls from Supabase (resume-derived profile, job data, hackathon results) plus approved external feeds.

## Virtual Hiring Panel
- Agents: HR, Tech Lead, Career Coach; each runs as a Gemini Flash 2.5 persona inside a LangGraph parallel branch.
- Inputs per evaluation: parsed resume/profile, manual profile overrides, AI interview transcript, job description, company culture notes.
- Standardized output: score 0–100, 1-sentence verdict (`Strong fit`, `Reach role`, `Not recommended`), justification, pros, cons.
- Cache panel reviews in Supabase (`panel_reviews`) so UI loads quickly and budget stays under control.
- UI pattern: panel card with headline score/tag plus collapsible agent summaries.

## Reverse Recruiter Agent
- Candidate-configurable filters: role keywords, industries, minimum salary (RM), preferred locations (KL, Penang, SG, remote), benefits, notice period.
- Daily job ingestion via RAG (Supabase `job_posts` + external feeds). Embed jobs + candidate preferences using Gemini embeddings stored in pgvector.
- LangGraph workflow ranks matches, writes to `agent_matches`, and triggers notifications (email/in-app).
- Provide explanation snippets (skills match, salary alignment, benefit match, location fit) for every surfaced job.
- Endpoint + scheduled runner allow manual refresh and automated scans without exceeding the USD 20 hackathon budget.

## Real-World Projects, Leaderboard, and Badges
- Host hackathons/business challenges/case studies directly on the platform.
- Tables: `events`, `event_registrations`, `project_submissions`, `digital_badges`, `leaderboards`.
- Every approved submission auto-attaches to the candidate profile as proof-of-work and feeds badge logic (Top 10%, Top 5%, Winner).
- Generate QR-verifiable badge URLs via Supabase edge functions so employers can trust credentials.
- Employer “Talent Command Center” aggregates leaderboard data, top projects, winners, skill-gap analytics, and blends with Hiring Panel scores for recommendations.

## Voice-to-Voice AI Interview (ElevenLabs + RAG)
- Keep ElevenLabs for TTS; stream candidate audio into Gemini Flash conversation orchestrated by LangGraph.
- Before each interview, build a RAG context bundle that includes:
  - Resume-derived education, experience, achievements, interests.
  - User-supplied preferences (location, salary, availability, employment status).
  - Stored hackathon/business challenge submissions and badges.
  - Target job description / employer problem statements.
- The interviewer agent uses this context to tailor industry-specific, scenario-based questions and follow-ups.
- Persist interview transcripts plus AI summaries for downstream agents (Virtual Panel, Reverse Recruiter) and to auto-populate profile fields when information is missing.

## Operational Notes
- Enforce Supabase RLS so candidates/employers only access authorized artifacts.
- Cache AI outputs aggressively; only re-run agents when source data changes.
